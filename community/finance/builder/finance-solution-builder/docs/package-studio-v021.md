# 业务资产 V0.2.1：展示聚合与操作引导

## 从组成读到文件

业务资产详情保留三个页签。默认六个阅读分组：专业方法、业务能力、数据与接口约定、银行接入、执行与观测要求、验证案例与结果。这些是展示索引，不是新资产格式或执行步骤。

点击分组，在详情选择成员；所属包及声明放在可展开列表。关系按钮可继续定位另一个分组的成员，浅红边框标出关联分组。手机端详情提供“返回业务组成”，恢复原分组及滚动位置。

“查看文件”直接定位真实文件；未读取到正文仅保留引用和原因。方法、所属包和 pack.yaml 不再作为概览中的平级卡片。未知类型保留在“其他引用与包信息”，原始节点、关系和版本不丢弃。

## 按状态操作

- **目录引用**：检查与生成 → 定制方法 / 用于创建 Agent / 下载开发样例。目录引用不是发布ZIP；不需要定制方法的查询能力可以直接构建。无独立Skill不表示错误，也不推断宿主提供方法。
- **草稿**：保存 → 校验依赖 → 运行受控检查 → 查看结果 → 核对发布条件 → 发布。问题链接定位正文、依赖、资料或案例。修改后旧试跑不再用于发布当前内容。
- **发布版本**：下载业务包 / 使用此版本创建Agent / 基于此版本创建草稿。派生通过该版本ZIP重新导入，不能复制当前未发布编辑内容；新草稿重新检查和验证。

生成Agent后在实例查看Lock和运行记录。资产详情中的关联只是构建时选择，不等于安装成功。Agent名称来自构建配置，未记录时如实提示。

## 开发入口

1. 改方法：编辑 SKILL.md、资料和案例，页面草稿可完成；不改Provider。
2. 组合：修改Solution引用和绑定配置；按已有装配入口检查与构建。
3. 新接口：修改外部合同、Provider及测试，需要编译、固定制品和受管准入。

开发样例下载物是带固定源码、README和source-lock.json的源码开发包，不是业务ZIP。当前在线发布范围仍为方法组件包，不强迫查询能力添加Skill，不支持上传代码后直接执行。

## 投影与边界

`asset-composition.v0.2` 增加可选 `readingGroups`，仅保存原始节点ID索引；每个节点恰好进入一个分组。前端按类型/职责渲染，不按金融业务ID分支。旧节点、关系与来源保持不变。

从详情定制使用统一目录的精确revision。旧草稿仍按原目录revision和来源摘要校验；未知revision继续拒绝，不通过放宽摘要门禁修复接线。

方法的 `allowed-tools` 表示声明使用；DomainPack能力范围不能推出每个Skill都调用；发布绑定不能当实际执行记录。通用结果Schema不是完整业务字段合同。观测要求不是采集证明。
