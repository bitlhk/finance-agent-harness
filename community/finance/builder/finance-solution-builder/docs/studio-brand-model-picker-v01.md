# Studio brand and model picker

The sidebar uses a fixed-height brand row with a compact Finance Harness wordmark,
an FH vector monogram and an aligned collapse control. The same monogram is embedded
as an SVG favicon in the page. Desktop, mobile drawer and collapsed navigation retain
their existing controls.

Runtime selection displays OpenJiuwen Python. Its Java financial bridge remains
part of the installed architecture and technical build evidence.

The model picker and model overview show at most three configured models. Existing
selected model references remain visible for compatibility; unavailable references
are not made executable by this presentation filter. The complete server catalog
and old artifact model snapshots are retained. No model credentials are embedded.

GLM-5.3-Flash is a separate catalog entry and is enabled only when the server binds
that exact model identity. The deployment connection was checked with an explicit
minimal inference request before enabling the binding. Catalog metadata alone never
grants a usable connection, and credentials remain server-side.

This presentation release can serve its three generated assets (index.html, app.js,
terminal.css) independently of the fixed Builder backend. Deployment evidence must
record both identities; it must not imply that the backend or existing Agents were
upgraded. All remaining routes retain their existing proxy and authentication rules.
