## 实现范围

1. 业务详情显示内置方法中文阅读说明、版本及源文件摘要；源变更即隐藏旧步骤并提示复核。
   可查看完整原文；中文说明不是当前草稿摘要、可执行译文或质量承诺。
2. 定制默认阅读，支持编辑原文；分为编辑方法、检查与试用、发布使用。
   保存草稿与 Java 受控检查不要求真实模型。禁用操作旁说明原因。
3. 首页提供导入 SOP、我的定制方法。详情内导入保留当前业务绑定，并单独记录
   `importedFrom` 与原始文件；不把上传文本冒充为内置方法正文。旧通用导入保留。
4. 统一余额查询、财富概览、收支分析显示名，技术 ID 不变。收支成组装配，按需调用。
5. 创建页集中展示能力、模型、银行配置阻断；连接管理只读，管理员配置后返回保留选择。
6. Python 安装证据原为 Python 注册记录与 Java 桥计划的组合，详情 API 原先只识别 Java Lock。
   本次补充识别与构建/工具集合/只读核验，返回 `PYTHON_REGISTRATION_WITH_JAVA_BRIDGE`，
   不把桥的 `VALIDATED_NOT_RUNTIME_REGISTERED` 改成 Python 已注册状态，不展示方法正文。

变更属于 Finance Solution Builder，不改 Base 契约、SDK 或银行授权逻辑。
新 `customize-import-preview` / `customize-import` 使用现有 owner、CSRF、上传限制及来源复核。
未发布的导入不生成工具、不增加实授；新方法版本发布仍须同修订的成功执行报告。
