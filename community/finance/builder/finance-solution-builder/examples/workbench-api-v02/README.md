# Interface Examples, Not Execution Evidence

Generated by `python engineering/export_workbench_api_examples.py`.
These are synthetic interface samples for UI development, not built or running Agents.
The sample manifest is intentionally incomplete; it must not be used to launch a host.

- `selection.schema.json`: generated from the same strict scenario extension used by HTTP validation.
- `catalog.json`: the finite directory and mandatory controls.
- `selection.json`: request body for both preflight and creating a build.
- `connections-missing.json`: local configuration absent; no connectivity claim.
- `build-succeeded.json`: artifact creation and instance readiness are separate.
- `instance-failed-build-preserved.json`: a launch failure does not erase a built artifact.
- `start-request.json`, `chat-request.json`: separate artifact, instance and session references.
- `authorization-rejected.json`: discard protected UI content, do not replay an old response.

Use `/api/bootstrap` first for the existing owner cookie and CSRF token. Endpoint details and
the AG-UI boundary are in `docs/workbench-api-v02.md`. No sample embeds credentials or host paths.
