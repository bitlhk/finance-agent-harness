# Shared Read-only Wealth Description V0.1

The host binds one principal, subject, purpose and session with currently granted
scopes. Required scopes in a Capability Pack do not grant authority. CUSTOMER
requires a matching bank Session subject; EMPLOYEE additionally requires a trusted
adoption-owner binding and the EA service's customer access decision.

The common view excludes names, contacts, relationship notes, internal knowledge
and raw governed profiles for BOTH roles because this task does not require them.
Changing this profile label never changes grants. Only source-reported assets,
risk assessment status, coverage/time and information gaps may reach the model.

No transaction, suitability or product recommendation capability is installed.
This is a profile boundary description, not a universal Profile Engine.
