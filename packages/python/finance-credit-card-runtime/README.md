# 信用卡领域运行包（reference）

信用卡领域包首批包含额度不足预测与权益推荐。运行代码独立于Builder，合成数据与模型训练留在Builder；不包含私有评分标签、凭据或模型权重。

Python 3.11.4–3.13。安装本包并按所用能力安装 `forecast` / `service` 可选依赖。模型制品和来源端口显式绑定；`Predictor` 加载验证后的制品，训练由 Builder 管理。

额度场景通过原生 ReActAgent 调用四个只读工具，使用同一总预算完成模型调用和至多一次结构校正。权益场景通过原生 WorkflowAgent 执行授权、意图理解、候选排序、资格与排除校验、记录。LLM 与外部 OneRec Worker 可使用同一候选池对照。

独立服务仅绑定 IPv4 回环，由宿主传入私有传输令牌及当次来源授权。`POST /v1/query`、`/v1/result`、`/v1/cancel` 分别提交、恢复、取消查询。模型参数不能指定来源地址、凭据或扩大可见范围。额度记录按租户、经理、客户、案例和会话分区；相同操作键仅重放相同输入，来源变化后停止采用旧事实。部署须保持单活协调器。

两类场景共用 `WorkbenchConversations` 保存对话目录与状态。用户侧的隔离单位是对话：独立消息、偏好链和执行线程；同一客户可对应多个对话，统一历史列表不按客户分组。客户是每次核查的业务上下文，更换时重新绑定来源与执行线程，旧消息保留所属客户和来源标识。存储按宿主的经理/租户及场景控制目录访问，修订比较后写入，支持同一受控状态目录下的进程重启恢复。

Builder 模板经现有 Experience 场景扩展装配客户选择、左侧对话列表、示例问法、范围图及权益卡。宿主负责提供授权客户和重新检查历史来源；浏览器不传入身份或任意来源地址。本组件先服务信用卡领域包的两个消费者，不新增 Core 会话框架。

来源回调、模型配置、状态目录及已有预测制品必须由宿主显式提供。新包不隐式导入概念机源码、Builder 或私有 oracle。当前仅支持合成 reference DTO；企业数据适配、生产身份/ACL及性能仍需专项验收。合同测试与安装态回放分别记录，依赖复用安装不计为干净离线安装。
