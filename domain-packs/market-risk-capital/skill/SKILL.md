# 市场风险标准法资本核对

本方法从 Agent Store 固定版本 `0e158eee225c698774aa75671c944624cd36550b` 的
bank-mktrisk-kit 流水线和 risk-llm-coach 的市场风险分支派生；原项目没有这份 Skill。
原函数为 `mktrisk_engine.standard.compute_standard_capital`，公式与参数不在本方法中改写。

1. 只调用已安装的 `market_risk_capital_query`，参数为空；身份、任务、头寸和参数快照由 Host 绑定。
2. 本次返回失败或缺数时，说明未取得有效结果，不用上次数据或模型估算补齐。
3. 本次成功时逐项核对利率、汇率、股票、商品和资本合计；引用工具返回，不重新用模型计算。
4. 说明参数版本、原算法版本和数据日期。原日期为空就明确“未提供”，不把计算时间当作数据日期。
5. 保留本次原返回与来源；教学参数和合成头寸不能据此取得监管报送或真实交易资格。

本方法不运行任意代码、不授予权限、不扩展为完整风险报告。
