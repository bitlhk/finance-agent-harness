# Finance Agent Harness

Finance Agent Harness 是面向金融 Agent 的行业能力与工程底座。

它不替代 Agent Runtime，也不是某个具体金融应用。它通过统一的金融合同、Profile、领域能力包、Runtime Integration、Provider Adapter、证据和评测机制，帮助岗位智能体、手机银行智能体及其他金融应用更快构建、验证和复用专业能力。

当前状态：`Architecture Baseline Draft`

首版聚焦：

- OpenJiuwen Runtime；
- 岗位智能体与手机银行两个真实应用；
- `employee-assisted` 与 `customer-self-service` 两种 Profile；
- 财富管理领域；
- Context、Action、Policy、Approval、Evidence 六类核心语义；
- 跨 TypeScript / Java 的一致性验证。

详细设计将在架构评审 PR 中维护。
